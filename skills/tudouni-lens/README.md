# 土豆泥图视 2.5.2

把想象，带到画面里。在熟悉的对话中，开启图片与视频创作。

安装后说“打开土豆泥菜单”。首次使用，在连接窗口填写自己的土豆泥 API Key；当前项目后续创作沿用已有连接。

你可以说“生图片”“生视频”“图片菜单”“视频菜单”“我的作品”或“继续刚才的任务”。菜单每次读取当前账号可用的图视模型，作品保存到当前项目。

Key 不需要发到聊天里。客户端需具备正常的工具运行能力，模型与价格以当前账号可用范围为准。
