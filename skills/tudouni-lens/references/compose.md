# 构图规格（与创作台同源）

用户口语先变成这份规格，再交给方言。字段不许私自加。

```text
用途: 封面 | 产品 | UI | 分镜 | 广告
画幅: 16:9 | 9:16 | 1:1 | 自定义
主体:
机位/构图:
光线/材质:
必须留下:
不准出现:
参考图角色: 风格 | 编辑对象 | 插入物 | 首尾帧
模型:
时长/秒: 仅视频
```

规则：
- 已够具体的提示词只做规范化，不添戏。
- 编辑必须写清「只改 X，其余不动」。
- `tudouni.lock.json` 的 `avoid` 并入「不准出现」；`refs` 按角色填参考图。
- 画幅：图转成 `1024x1024` / `1536x1024` / `1024x1536`；视频保持 `ratio`。
- 输出给 CLI 的是 JSON 规格，不是散文。
